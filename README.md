1. В файле basic_level находится задание из базового уровня. Это программа запрашивает число и выводит на экран квадрат этого числа.

2. В файле medium_level находится задание из среднего уровня. Это программа запрашивает число и выводит на экран квадрат и куб этого числа.

3. В файле elevated_level находится задание из повышенного уровня. Это программа запрашивает катеты прямоугольного треугольника, вычисляет
   гипотенузу этого треугольника и выводит на экран периметр и площадь.
