1. base.cpp - Запросить два числа. Если они равны, вывести "Равны", иначе вывести "Не равны"
2. medium.cpp - Запросить число от 0 до 100 (оценку). Вывести буквенную оценку: A (90+), B (75-89), C (60-74), D (50-59), F (ниже 50). Если число вне диапазона — ошибка
3. elevated.cpp - Квадратное уравнение с комплексными корнями: решить квадратное уравнение. Если дискриминант отрицательный, вывести комплексные корни в формате "x1 = a + bi, x2 = a - bi". Обработать случай a=0, b=0
